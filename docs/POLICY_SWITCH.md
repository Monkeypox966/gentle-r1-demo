# 柔顺 / 非柔顺策略选择

控制面板增加一个简洁的策略选择框：默认柔顺Gentle，另可选择非柔顺Vanilla-RL。两者均为真实训练完成的独立学生网络，共用原网页模型、PD、接触、七种参考与外力交互，不通过改关节刚度或播放姿态制造差异。

Vanilla导出仅只读访问训练项目，未生成额外训练数据或改写源码/权重。网络含冻结归一化、适配MLP、学生动作均值，392维输入/24维输出。CPU ONNX对独立PyTorch推理验证41个输入，最大绝对误差2.3842e-6；现有Gentle模型和Python oracle未改变。详情在vanilla-export.json与ASSET_PROVENANCE.json。

策略文件按需加载、SHA校验并暖启动后才生效；失败则保持原会话、恢复真实选项并显示错误。动作和策略共用最新请求优先的事务，旧下载即使晚到也不得覆盖新选择。最多缓存两个会话，避免每次切换重新下载。

切换会保留参考动作并复位物理状态、滤波、观测历史、计时及拖动力；运行中的仿真成功切换后继续，失败则暂停。弹簧开关保留，锚点随复位重建。非柔顺策略不使用柔顺力调节，滑块禁用、网络相应条件固定10；两种策略的鼠标施力、弹簧及轻推仍使用同样物理逻辑。

两次训练的环境修订不同，因此本网页提供交互体验对比，不是严格的单变量论文消融，也不保证刚性/柔顺策略在任意外力下不会失稳。原动态参考是自主生成的精选示例，未发布训练数据。

## 浏览器验收

自动验收包含两网络独立Python oracle、Vanilla七种动作各12秒闭环及行走位移、原Gentle十四组闭环回归、实际鼠标施力与撤力、轻推、运行中切换并继续、返回Gentle数值一致、非柔顺条件输入固定10、下载失败回退以及策略/动作交错加载的最新请求优先。测试执行使用CPU8/9、6GiB上限、软件WebGL和原全局仿真锁。

最终记录在validation-policies.json，截图为policy-gentle.png、policy-vanilla.png及policy-mobile.png；发布前须完成本地与GitHub Actions浏览器验收。

本地生产构建已通过全部验收。两网络浏览器对各自Python oracle的误差约1.67e-6，同输入下Vanilla与Gentle动作最大差约5.38；返回Gentle后的数值对照仍通过。Vanilla步行12秒实际前进约1.88m，七动作均无保护故障；真实10N轻推、鼠标施力/撤力、跨动作与策略的乱序返回验证均通过。默认Gentle的十四组原物理回归也全部通过。
